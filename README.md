# 🎮 Tic Tac Toe - Python Terminal Game

A simple and interactive **Tic Tac Toe** game built with Python. The game runs in the terminal and supports two players taking turns.

## 🚀 Features

- 👥 Two-player gameplay (X and O).
- 🎯 Interactive terminal interface.
- ✅ Win detection.
- 🤝 Draw detection.
- 🔒 Prevents selecting occupied positions.
- 🔄 Play again option.
- ⚠️ Input validation.

## 🛠️ Technologies Used

- Python 3
- Built-in Python Functions
- Lists and Loops
- Conditional Statements
- Functions

## 📥 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/Mostafa-Makram/Tic-Tac-Toc_X_O_Game.git
```

### 2. Navigate to the Project Directory

```bash
cd Tic-Tac-Toc_X_O_Game
```

## ▶️ How to Run

Run the following command:

```bash
python tic_tac_toe.py
```

## 🎮 How to Play

1. The game starts with an empty 3x3 board.
2. Player X starts first.
3. Players take turns choosing a number from 1 to 9.
4. The first player to get three symbols in a row, column, or diagonal wins.
5. If all positions are filled without a winner, the game ends in a draw.
6. Choose whether to play again.

### Board Positions

```text
 1 | 2 | 3
---+---+---
 4 | 5 | 6
---+---+---
 7 | 8 | 9
```
